For You ♡ — Romantic envelope website

Included:
- Responsive design for phones, tablets, laptops and desktop
- Password screen (currently: my wife)
- Envelope opening animation
- Your message copied into the page as supplied
- Uploaded MP3 in assets/song.mp3 with repeat enabled

Preview locally:
1. Extract the ZIP.
2. Open index.html in a modern browser.

Important:
The password is client-side in this simple static version; it is a playful gate, not strong security. To share it publicly with real privacy, move password verification to a server.
To publish online, upload the contents of this folder to a static hosting provider. Keep the assets folder alongside index.html.
